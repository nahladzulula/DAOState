# DAOState

DAOState is an intelligent state-machine-based manager that utilizes event-driven architecture to optimize decentralized application operations.

With DAOState, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/DAOState.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

DAOState is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
